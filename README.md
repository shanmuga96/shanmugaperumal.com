# Shanmugaperumal.com

Personal website and digital portfolio of Shanmugaperumal Seenivasan.

This project brings together my work as a Full Stack Software Engineer, Writer, and Poet into one place.

The website is intended to be a single home for my professional work, software projects, writing, poetry, and personal experiences.

## ✨ About the Project

Shanmugaperumal.com is a personal website built from the ground up with a focus on:

- Simplicity
- Accessibility
- Performance
- Responsive design
- Maintainability
- Personal storytelling

The website will bring together content and work currently spread across platforms such as Medium, Blogger, Miraquill, LinkedIn, and GitHub, while preserving links to the original publications and profiles.

## 📝 Writing

Writing is an important part of this website.

The platform will provide a central place to discover:

- Articles
- Essays
- Poetry
- Personal reflections
- Experiences
- Ongoing writing series

Original publications will continue to be credited and linked to their respective platforms where applicable.

## 💻 Projects

The Projects section will showcase selected software engineering projects, experiments, and open-source work.

Where appropriate, projects will link directly to their corresponding GitHub repositories.

## 🛠️ Tech Stack

- **Next.js** — React framework
- **TypeScript** — Type-safe development
- **React** — UI development
- **Tailwind CSS** — Styling
- **ESLint** — Code quality
- **GitHub Actions** — CI/CD and automation

## 🏗️ Project Structure

```text
src/
├── app/          # Application routes, pages and layouts
├── components/   # Reusable UI components
├── data/         # Static application data
├── lib/          # Utilities and shared logic
├── styles/       # Global and shared styles
└── types/        # TypeScript type definitions

public/           # Static assets

docs/             # Project documentation
```
